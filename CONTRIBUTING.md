# Contributing

Issues and pull requests are welcome.

Before opening a pull request:

1. Create a focused branch.
2. Run the checks in `TESTING.md`.
3. Do not commit copyrighted books, OCR model weights, generated PDFs, private logs, or local virtual environments.
4. Describe the PDF type and layout without uploading protected source material.
5. Include a minimal synthetic or public-domain reproduction when possible.

Keep changes scoped and preserve local-only document processing.
